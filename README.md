# Deposit Pelanggan

Aplikasi untuk membantu mencatat deposit pelanggan, saldo yang tersedia, dan riwayat perubahan saldo.

## Tujuan

Menjaga catatan deposit setiap pelanggan tetap jelas dan dapat ditelusuri, termasuk saat deposit ditambahkan, digunakan, atau dikoreksi.

## Cakupan awal

- Data pelanggan.
- Penambahan deposit.
- Pemakaian deposit.
- Saldo berjalan.
- Riwayat transaksi.
- Koreksi transaksi yang terlacak.
- Pencarian dan laporan dasar.

Bentuk aplikasi, cara penyimpanan data, dan aturan bisnis rinci belum ditetapkan.

## Status
